# Spike S-1: HealthKit Background Delivery auf dem Gerät (offen, Lino)

**Stand:** 25.11.2026 · Software (M3) ist gegen eine Fake-Quelle getestet; auf einem Gerät ist **nichts** davon erprobt. Dieses Protokoll wird beim Test ausgefüllt (PLAN.md M3, PLATTFORM F-01…F-04, F-14).

## Voraussetzungen
- Signierter Build auf dem iPhone (die App ID braucht HealthKit und Background Delivery; Entitlements stehen in `project.yml`).
- Onboarding Schritt 2 oder Einstellungen > Apple Health: verbinden, Zeitraum wählen.
- Beobachtet wird in Einstellungen > Apple Health („Letzter Abgleich“, Status) und im Verlauf.
